# NitroRecomp

Proyecto experimental de investigación y desarrollo de herramientas para facilitar el modding de **Nitroplus Blasterz: Heroines Infinite Duel**, estudiar sus formatos de archivos y explorar futuras adaptaciones a otras plataformas.

Actualmente está en una fase inicial de investigación. Este repositorio no incluye el juego, sus recursos ni sus ejecutables. Las futuras herramientas requerirán una copia propia del juego.
